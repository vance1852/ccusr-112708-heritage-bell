# 历史街区多点报时的现场同步与静音改场

历史街区扬声站、报时源和节目播放终端的本地联调。 目录中的记录为本地合成联调资料。

- `data/site.json` 保存现场配置及设备消息各类型的字段顺序。
- `data/frames.jsonl` 保存不同设备和工作人员提交的消息，逐行解码。

`arrival` 是资料中的接收序号，`captured` 是来源记录的现场时刻，单位为秒。`received` 是边缘收到消息的时刻，使用同一时间单位。设备补送仍携带原现场时刻。`source` 表示消息来源，`type` 是消息名称，`args` 按现场配置列出的顺序给出原值。每行记录一次接收，包括重复消息。设备此时的状态应按对应设备协议解释。

所有样本使用合成音节目编号。时钟回报给出本地相对统一时间的偏差、误差上界（毫秒）和时钟代次。播出状态带节目版本。区段包含使用中的实际覆盖位置。

使用 Python 3.11 标准库即可读取资料和执行资料测试，无需网络或外部设备。

```text
python3 device_replay.py
python3 -m unittest discover -s tests -v
```

读取程序逐帧输出原始联调消息。配置、载荷字段数及逐帧回放可通过资料测试核对。
